07 · LIMITATIONS

What CareKitchen cannot yet claim

Evidence is synthetic

Every case is invented. Each version was run once. “Users” in the browser tests were AI agents, not older adults. Pass counts are engineering checks, not proof of nutritional quality or user success.

Small meal library

The model ranks and explains a library written by the project. Variety is limited, and meals are Taiwan-style home dishes.

Prices only as typed

There is no live market data. Unknown prices stay unknown, so many results read “total pending”.

Not a clinical tool

No nutrient values, no allergen cross-contact guarantee, and processed foods may hide ingredients. Users must read labels and ask professionals.

Reliability

The service depends on an external model API. One unexplained execution error occurred in testing. On failure it shows an error, never an invented recipe.

Accessibility and language

Simple mode and large text exist, but no WCAG audit or test with older adults has been done. The interface is Traditional Chinese only.

Hallucination and bias. Free generation is limited by design, but ranking and wording can still be wrong. The meal library and defaults reflect one food culture and assume access to common kitchen equipment.
