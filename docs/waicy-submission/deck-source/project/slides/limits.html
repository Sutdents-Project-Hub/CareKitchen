07 · LIMITATIONS

What CareKitchen cannot yet claim

Evidence is synthetic

Every case is invented and each version ran once. Browser “users” were AI agents, not older adults. Pass counts are engineering checks, not proof of user success.

Small meal library

The model ranks a library written by the project. Variety is limited to Taiwan-style home dishes.

Prices only as typed

There is no live market data. Unknown prices stay unknown, so many results read “total pending”.

Not a clinical tool

No nutrient values and no allergen cross-contact guarantee. Processed foods may hide ingredients.

Reliability

It depends on an external model API. One unexplained error occurred in testing. On failure it shows an error, never an invented recipe.

Accessibility and language

Simple mode and large text exist, but no WCAG audit or test with older adults. English reviewer flow tested on synthetic cases. Additional language and dialect coverage has not been established.

Hallucination and bias. Free generation is limited by design, but ranking and wording can still be wrong. The library and defaults reflect one food culture and assume common kitchen equipment.
