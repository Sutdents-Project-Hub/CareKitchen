ORIGINALITY AND CREATIVITY

What CareKitchen adds, and what it builds on

Says “not yet known”

Each meal carries a price state, so a missing price stays missing instead of being guessed.

Confirmed versus unsure

Only confirmed restrictions become hard filters. Vague ones trigger a question; the model cannot lift a limit.

AI ranks, code verifies

The model reads intent and ranks. Recipes, sums and exclusions stay under testable rules.

Safety before the model

Medication and symptom questions are referred by server rules, with no model call.

One state, three roles

The same conditions become short choices, a restriction check or a shopping handoff.

Honest explanations

“Why these?” is answered from the shown recipes’ foods and purchases, not invented reasoning.

BUILT IN THIS PROJECT

Recipe catalog, condition editor and English parser, eligibility and whole-package price checks, role guidance, conversation flow and test records.

BUILT ON

GPT-6 Luna (OpenAI); Next.js, React, TypeScript, Zod and Vercel; published statistics and studies.
