ORIGINALITY AND CREATIVITY

What is new in this project

An advisor that can say “not yet known”

Every meal carries one of three price states, so a missing price is shown as missing instead of being guessed.

Confirmed versus unsure restrictions

Only restrictions the user confirms become hard filters. Vague ones trigger a question, and the model can never lift a limit.

The AI proposes, code verifies

The model reads intent and ranks. Recipes, sums and exclusions stay under rules that can be tested.

Safety decided before the model

Medication and symptom questions are referred by server rules, with no model call.

One state, three roles

The same conditions become short choices, a condition check or a shopping handoff, without weakening safety.

Failures kept on file

Raw runs, prompt fingerprints and an unexplained error are public, so claims can be checked.
