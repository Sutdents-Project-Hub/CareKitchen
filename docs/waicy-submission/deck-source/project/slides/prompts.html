ITERATIVE DESIGN · STAGE 2: ADVISOR DESIGN

From the first prompt to English V6

VersionDesignWhat it was meant to fix
BaselineOne line, “Answer the user in Traditional Chinese” (later in English). Plain chat history, free text.Reference point: the same model with no CareKitchen design.
V1The model classifies the turn and ranks candidates. It may ask about any unknown.First end-to-end meal advisor.
V2Server-parsed conditions are trusted. A clarification must name the missing field and quote the user.Needless re-asking, lost spoken edits, no way to enter prices.
V3Mentioning a budget is separated from asking for a shopping list. Reasons and screens depend on the role.All three roles got the same shopping summary.
V4The server parses everyday phrasings; the prompt stresses exclusions and budget changes not yet applied.“No egg today”, “keep it under 70”, “no cooking today”, “now two of us”.
English V5English instructions with the same ranking, evidence and referral boundaries.An English service with its own test runs and transcript.
English V6Role guidance names checkable tie-breakers. The server reads short phrases, ranks pantry matches first, explains and swaps.“Dinner for 1” unread, foods dropped, “an oven” stored as food, follow-ups not understood.

Same settings in every run: gpt-6-luna, reasoning effort none, store false. V1–V4 wording is translated from Chinese. V2 and V3 prompt files were reconstructed from known differences, not archived at the time.
