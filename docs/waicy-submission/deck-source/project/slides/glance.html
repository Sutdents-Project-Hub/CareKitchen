WHAT IT IS

A chat advisor for everyday home meals: 2–3 candidates, short steps and a shopping summary that respects budget, equipment and confirmed restrictions.

WHAT IT IS NOT

Not a diagnosis, drug–food interaction checker, medical diet or live price service. It never guarantees that a meal is safe.

WHAT IS VERIFIED

Real model runs on synthetic cases, with raw outputs saved. Not yet done: tests with real older adults and a public deployment.
