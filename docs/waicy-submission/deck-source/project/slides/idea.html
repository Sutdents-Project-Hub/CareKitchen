05 · ITERATIVE DESIGN · IDEA EVOLUTION

From a clinical idea to an everyday meal conversation

BEFORE 20 NOV

Original concept

An advisor aware of drug–food interactions. Needs clinical validation we could not honestly provide.

20 NOV

Reframed

Plan meals from pantry, budget, equipment and confirmed restrictions. Refer medical questions out.

21 NOV

Specification

3 personas, 10 core features, 14 acceptance cases and 30 planned test cases (not all run).

22 NOV

First prototype

Working web app with an OpenAI connection, then an interface redesign.

23 NOV

Tested and fixed

Baseline and V1–V4 runs, a fresh-scenario check, fixes and screenshots.

WHY THE IDEA CHANGED

A drug–food checker would need professional review and could cause harm if wrong. A meal conversation can be tested honestly, and still serves safety by refusing to guess.

HOW WE WORKED

Every version was run against the same saved cases with the same model. Raw outputs, prompt hashes and Git commits are kept so each change can be traced. The whole cycle ran from 22 to 23 November 2026.
