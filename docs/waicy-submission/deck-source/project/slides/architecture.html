THE SERVICE · AGENT DESIGN

The AI proposes, and the server verifies

1

User turn

Free text plus the condition form: people, budget, pantry, equipment.

2

Server parser

Updates one canonical state. An edit overrides only its own field.

3

Safety check

Medication, symptoms or unclear restrictions: ask or refer, no model call.

4

LLM decision

GPT-6 Luna returns a structured choice: intent and a ranking of eligible meals.

5

Validators

Exclusions, equipment, servings and price engine decide what is shown.

The model cannot invent

Ingredients, prices and steps come from a project-written meal library and the user’s own inputs.

Cost is computed by code

Whole packages the user must buy, using prices the user supplied. Missing prices show as pending.

Keys stay on the server

The API key is only in server settings. Responses use store: false and outputs are schema-checked.
