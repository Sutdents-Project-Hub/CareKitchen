# CareKitchen 真人試用

邀請 2–3 位成年親友，每人約 8–10 分鐘。請對方帶一個近期真的要處理的備餐需求，用平常使用的手機或電腦操作。每人選一個與自己最接近的任務。

## 可直接傳的邀請

> 可以借你大約 10 分鐘嗎？我們想請你用 CareKitchen 規劃一餐。請想一餐你這幾天真的會準備或幫忙採買的餐點，用你手邊有的食材和設備來試。你只要像平常一樣操作，遇到哪裡不清楚就跟我說。

## 主持人開場

> 今天想看看這個網站能不能幫你準備那一餐。操作時可以邊做邊說你在找什麼，隨時可以停。你願意讓我記下匿名的操作結果，放進專案簡報嗎？請只輸入和備餐有關的食材、份量、設備與價格，請省略姓名、聯絡方式和健康資料。

## 開始前問三句

1. 「你想安排哪一餐？這次通常是誰決定菜色或採買？」
2. 「你已經知道哪些條件？哪些要等一下再確認？」
3. 「你平常會怎麼處理這件事？今天最想從網站拿到什麼？」

開啟 [CareKitchen](https://carekitchen-theta.vercel.app/)，把裝置交給對方。網站介面是英文。若對方需要翻譯，先請他說出原本要輸入的內容，再照原意翻譯，並記在表上。價格、份量或限制尚未掌握時，可留白或說明待確認。

## 遇到卡住時

先等對方自己找。若他停下來，依序問「你在找什麼？」和「你原本預期這一步會出現什麼？」仍需要協助時，才指出可用的控制項或解釋畫面，並記下提示後的結果。

# 給參與者的任務卡

請從最近真的要準備的一餐出發。選擇符合你當下需求的角色，直接在網站上完成。

## A．替自己備餐

選 **Cooking for myself**，輸入用餐人數、手邊食材與可以使用的設備。挑一道你真的會考慮做的菜，打開 **View simple steps**。

**主持人問**　「你會選哪一道？手邊哪些食材能用？開始煮以前，還有哪個份量或品項要確認？」

**核對畫面**　有沒有找到料理步驟？對方能不能指出哪項食材在家裡、哪項還要準備？若沒有合適的菜，他能否說明網站提出的下一步？

## B．替家人備餐

選 **Cooking for someone I care for**。輸入這餐的實際條件，再補上一項原先漏填或最近確定的變更，例如出席人數、設備或要避開的食材。看看建議怎麼調整。

**主持人問**　「這次哪一項變了？哪些原本的條件還要保留？你從畫面哪裡看出來？」

**核對畫面**　是否找得到更新後的條件？若兩次輸入都缺少必要資訊，是否看得懂該補什麼？如果近期沒有變更，請對方核對人數與設備，並記錄這次只做了條件核對。

## C．幫忙採買

選 **Planning with family**，用一餐真的要準備的需求取得建議。打開 **Preview and copy meal summary**，把摘要複製到自己的空白備忘錄。

**主持人問**　「看到這份摘要，你打算買什麼？金額已確定了嗎？還有什麼要問家人或商店？」

**核對畫面**　是否能開啟及複製摘要？是否分得出已有、待買、價格待確認？如果目前沒有待買品或所有價格都有資料，把對方實際看到的狀態記下來。

# 匿名觀察紀錄

每位一張。開始前取得同意，使用編號而非姓名。填好的紀錄由團隊私下保存。公開簡報引用原話時，先讓參與者確認可使用的內容。

| 欄位 | 紀錄 |
|---|---|
| 編號、日期、裝置 | |
| 任務與實際想完成的事 | |
| 參與者輸入或點選 | |
| 網站的回覆或畫面變化 | |
| 參與者怎麼理解這個結果 | |
| 第一次卡住的地方 | |
| 主持人提示與後續變化 | |
| 結果 | ☐ 獨立完成　☐ 提示後完成　☐ 未完成　☐ 未執行 |
| 參與者打算採取的下一步 | |

**判定方式。** 能自行操作並說出任務的關鍵結果，記為獨立完成。若主持人指出下一個按鈕或替他解讀結果，記為提示後完成。若只協助翻譯，記錄翻譯本身，以免和操作提示混淆。

## 結束時逐題問

1. 「你原本想完成什麼？做到哪一步？」
2. 「哪一個回覆讓你知道可以繼續？哪一個讓你需要停一下？」
3. 「現在要準備這一餐，你會採取什麼下一步？」
4. 「如果網站只能改一個地方，你會改哪裡？為什麼？」

# 試用結果的素材整理表

## 方法說明

請參與者用平常使用的裝置，從近期真的要準備的一餐開始。觀察三類需求：自己備餐時能否找到做法，替家人備餐時能否確認份量及保留原本的條件，協助採買時能否辨認待買品項和待確認的價格。

## 可整理成一段的試用紀錄

| 素材 | 填入實際紀錄 |
|---|---|
| 使用者當時想做什麼 | |
| 輸入的問題或按下的控制項 | |
| 網站的實際回覆或畫面 | |
| 參與者的實際回答或下一個動作 | |
| 哪一步需要提醒？提醒後有何變化？ | |
| 改了什麼？後續重測結果（如有） | |

**中文結果句型**

> 共＿＿位參與者使用 CareKitchen 處理近期的備餐需求。其中＿＿位獨立完成、＿＿位提示後完成、＿＿位未完成。在＿＿步驟，有人＿＿。當時網站顯示＿＿，參與者接著＿＿。

**英文結果句型**

> [Number] participants used CareKitchen to plan meals they expected to make or help with. In the [task] flow, [number] finished independently, [number] finished with a hint, and [number] did not finish. At [step], [observed action or difficulty] occurred. The site displayed [actual response], and the participant then [actual next action].

不同任務分開計數。引述前核對原話與使用同意；若有修改與重測，可另附一筆前後對照。
