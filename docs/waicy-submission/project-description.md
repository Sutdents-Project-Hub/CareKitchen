# Submission Form Project Description

Copy-ready English text. The WAICY form allows up to 200 words.

> CareKitchen is a conversational AI meal planner for older adults who cook alone, family caregivers, and relatives who help coordinate meals. Users enter ingredients at home, a serving count, equipment, a shopping budget, and confirmed exclusions. The assistant suggests eligible dishes with simple cooking steps. It recalculates portions, costs, and exclusions when users ask to change a meal.
>
> GPT-6 Luna ranks recipes that pass server checks. CareKitchen calculates purchases from the package prices provided by the user and flags missing prices or quantities. It offers a previewable shopping summary and refers medication or symptom questions to a qualified professional.
>
> A judge-style English review revealed that the deployed app missed phrases like “Dinner for 1,” interpreted an oven as food, and sometimes ignored ingredients. We repaired those flows and met all 12 targeted checks on the same inputs. A Codex-operated browser session recorded ten rounds with the final assistant, using fictional meal details. The project includes raw results, a public conversation, and a working chatbot link.
